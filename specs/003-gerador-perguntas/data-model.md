# Data Model: Gerador de Perguntas

This document describes the entities, attributes, relations, and validations required for the Question Generator feature.

## 1. PromptConfig (Extended Entity)

The `PromptConfig` entity, which represents saved prompts configuration in `prompts.json` and is validated by Pydantic on the backend, is extended to differentiate which tool a prompt belongs to.

### Schema Attributes
| Attribute | Type | Validation Rules | Description |
|:---|:---|:---|:---|
| `id` | `str` | UUID v4 format | Unique identifier. |
| `nome` | `str` | `1 <= len <= 100` | User-friendly name. Must be unique (case-insensitive). |
| `tipo` | `TipoPrompt` | Enum: `"FIXO"`, `"CUSTOMIZADO"` | Fixo represents built-in defaults; customizado are user-defined. |
| `textoInstrucao` | `Optional[str]` | `10 <= len <= 5000` | System instruction prompt. Required for `CUSTOMIZADO`. |
| `palavrasChave` | `List[str]` | Optional | List of keywords to bias extraction. |
| `idiomaModelo` | `str` | Default `"pt-br"` | Target output language code. |
| `modeloOpenAI` | `ModeloOpenAI` | Enum: `"gpt-4o-mini"`, `"gpt-4o"` | OpenAI model to use. |
| `ferramenta` | `TipoFerramenta` | Enum: `"extrator"`, `"gerador"` | Identifies which tool the prompt applies to. Default: `"extrator"`. |

### DB Migration / Startup Hook
- On system load, the `PromptStorageService` reads `data/prompts.json`.
- It performs an automatic schema migration by detecting objects missing the `ferramenta` field, setting their value to `TipoFerramenta.EXTRATOR`, and flushing the migrated list back to disk.
- It ensures two default system prompts are seeded (one for `extrator`, one for `gerador`).

## 2. ResultadoParPR (Reused Entity)

The question generator outputs Q&A pairs matching the existing entity schema to ensure compatibility with standard exporting tools.

### Schema Attributes
| Attribute | Type | Description / Constraints |
|:---|:---|:---|
| `perguntaPadronizada` | `str` | Formulated question generated by the AI based on the input statement. |
| `respostaConsolidada` | `str` | The original factual statement/rule of business that serves as the answer. |
| `frequencia` | `int` | Starts at 1. Increases incrementally if duplicate questions are consolidated. |
| `metadata` | `Optional[str]` | Categorization tag generated by the AI (e.g. "Preços", "Suporte"). |
| `category` | `str` | Defaults to `"FAQ"`. |

## 3. WSStartMessage (Reused client payload, contextually filtered)

The WS message sent by the client to initiate the generator queue must follow the same schema as before:

```json
{
  "action": "START",
  "key_id": "api-key-uuid-or-env",
  "prompt_id": "prompt-config-uuid",
  "files": [
    {
      "nomeArquivo": "documento.txt",
      "conteudoBruto": "Texto contendo fatos..."
    }
  ]
}
```

### Validation
- `prompt_id` MUST point to a prompt that matches `ferramenta === TipoFerramenta.GERADOR`.
